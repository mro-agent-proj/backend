# 평가셋 (eval)

| 폴더 | 무엇을 보나 | 데이터 | 건수 | 실행 |
| --- | --- | --- | --- | --- |
| [`scenario/`](scenario/README.md) | **통합 평가**: 신고 접수부터 배정까지 전체 흐름이 기대대로 가는지 | 시드 기체·수리이력에 맞춰 손으로 만든 한국어 시나리오 | AI 경로 23 + 접수 검증 6 | `scripts/scenario_eval.py` (스택 전체 필요) |
| [`sdr/`](sdr/README.md) | **단위 평가**: 검색(R01·R02)·LLM1 분류·LLM2 부서 결정을 하나씩 | FAA 공개 SDR 2019~2020 (검색 대상과 기간이 겹치지 않음) | 검색 400 · 분류 200 · 부서 200 · 매핑 548 | 각 평가 대상별로 (아래 README) |

- 통합 평가는 "시연 흐름이 맞게 도는가", 단위 평가는 "각 부품이 얼마나 정확한가"를 봅니다. 결과가 나쁠 때 어느 단계가 원인인지는 단위 평가로 찾습니다.
- 두 평가셋 모두 실제 항공사 운영 데이터의 성능을 뜻하지 않습니다.
